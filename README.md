# Mosammat Samira Sharmin — Portfolio

A responsive, privacy-conscious portfolio for a humanitarian and community development professional. The site is built with plain HTML, CSS, and JavaScript, so it can be hosted directly on GitHub Pages without a build step.

## What is included

- Professional landing page with responsive mobile navigation
- About, expertise, experience, education, training, language, and contact sections
- Profile photo extracted from the supplied CV
- Print-ready public CV at `resume.html`
- Accessibility support, reduced-motion support, and print styling
- No frameworks or package installation required

## Preview locally

Open `index.html` in a browser. For the most accurate preview, run any simple local web server from this folder.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `samira-portfolio`.
2. Upload these files to the repository or push this folder with Git.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will show the public website URL after deployment finishes.

For a personal root site such as `username.github.io`, name the repository exactly `username.github.io`.

## Privacy note

The public website and public CV intentionally exclude the NID, date of birth, marital status, and private contact details of professional referees from the supplied CV. Do not upload the original PDF publicly unless those details have been removed.
